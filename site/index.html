A coding agent you run yourself

Documentation

How Tacit works, where each setting lives, and which line of code decides it. Every citation is a file and a line you can open.

One Python program serving plain web pages. No build step, no frontend toolchain, no database to install. The fixed cost per turn is the smallest in its class, nothing optional is on until you turn it on, and the sandbox reports what it actually enforces.
