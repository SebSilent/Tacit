A coding agent you run yourself

The coding agent where nothing is hidden

How Tacit works, where each setting lives, and which line of code decides it. Every citation is a file and a line you can open.

One Python program serving plain web pages. No build step, no frontend toolchain, no database to install. The fixed cost per turn is the smallest in its class, nothing optional is on until you turn it on, and the sandbox reports what it actually enforces.

The interface

The whole app, with no server behind it

The frame below loads demo.html?view=basic, which the build generates out of static/index.html and static/style.css rather than drawing: the top bar, the transcript, the tool cards and the meter are the real parts, driven by one scripted turn with a pointer that moves to the composer, types the ask and presses send. The sidebar is dropped inside the frame, because a list of sessions nobody can click is decoration. The whole thing, with the Assistant asked several questions per session, the Delegation panel, the terminal, the Git panel and the Prompts tab, is demo.html full screen. The documentation pages are text.

Open full screen How the interface works

Nothing in the frame touches your machine: there is no backend, no WebSocket and no disk. The transcript is a script, the theme list and the prompt texts are copied out of the repository at build time, and the handlers are written against the app's markup rather than being the app's own, because the app's scripts have no server here to talk to.
