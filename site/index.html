A coding agent you run yourself

The coding agent where nothing is hidden

How Tacit works, where each setting lives, and which line of code decides it. Every citation is a file and a line you can open.

One Python program serving plain web pages. No build step, no frontend toolchain, no database to install. The fixed cost per turn is the smallest in its class, nothing optional is on until you turn it on, and the sandbox reports what it actually enforces.

A turn drawn with the interface's own parts, and no server behind it. The tool cards open, the thinking block collapses, the task strip sits outside the transcript where a compaction cannot summarise it away, and the panel on the right is the Assistant: a second conversation the agent is never told exists. The counter in the bar is the context window filling as the turn spends it.
