Local-first coding agent

The coding agent where nothing is hidden

A coding agent you run yourself. One Python program, plain web pages, no database. Every decision lands in a file you can read, and the cost of a turn is measured before you send it.

Re-derived from the code by a test on every run. Characters divided by four, the same heuristic the token meter uses. The preamble is one term you can see and set; the bill also depends on steps and transcript.

Nothing optional is on

Memory, sandboxing and learning start off. A capability you did not enable costs no schema, no prompt text and no worker.

02

It reports what it enforces

Where the platform cannot isolate a command, the result says so plainly. The sandbox only claims a guarantee it can actually keep.

03

Nothing is learned without you

A proposal is a stored artifact you read and decide on. The analyzer registers no tool and adds no prompt text.

The interface

The real app, running with no server

This frame is generated from the app's own markup and stylesheet, driven by one scripted turn. It is not a drawing of the interface. Type in the composer and it answers. The full surface, including the Assistant, Delegation, terminal, Git and Prompts panels, is demo.html full screen.

Open full screen How the interface works

Nothing in the frame touches your machine: no backend, no WebSocket, no disk. The transcript is a script and the prompt texts are copied from the repository at build time.
